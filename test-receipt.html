🎨 Aperçu du reçu

Le reçu inclut :

  • ✅ Icône de succès verte
  • 📅 Date et heure du paiement
  • 🔢 Référence unique de transaction
  • 📦 Pack souscrit (ESSENTIEL/PREMIUM/ELITE)
  • 👤 Nom et email du client
  • 💰 Montant payé en gros caractères
  • ⚡ Liste des prochaines étapes
  • 📞 Informations de contact
  • 🖨️ Bouton pour imprimer

🔄 Flux complet

  1. Client sélectionne un pack → Modal s'ouvre
  2. Remplit le formulaire → Validation des données
  3. Clique sur "Payer" → Redirection NotchPay
  4. Effectue le paiement sur NotchPay
  5. NotchPay redirige vers /mailodie-join avec paramètres
  6. Reçu s'affiche automatiquement ✅
💡 Astuce :
Pour tester différents scénarios, modifiez les paramètres dans l'URL :
  • pack : MAILODIE ESSENTIEL / PREMIUM / ELITE
  • amount : 40000 / 96000 / 200000
  • name : Nom du client
  • email : Email du client
